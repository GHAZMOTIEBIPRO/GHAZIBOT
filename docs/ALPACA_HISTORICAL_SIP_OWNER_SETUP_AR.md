# تشغيل مسار Alpaca SIP التاريخي البحثي — GHAZI RADAR

**الحالة الافتراضية: مغلق تمامًا.** هذا المسار لا يضيف أسعارًا مباشرة إلى الموقع العام، ولا يرفع أهلية تنفيذ عقود CALL/PUT ولا يغيّر V11. هدفه تحسين تغطية شموع الأسهم اليومية المغلقة لاختبارات VCP وتجارب البحث الداخلي.

## 1. سبب اختيار المصدر

- IEX المجاني يعكس تداول بورصة واحدة فقط، فلا يعكس جميع أحجام الأسهم الأمريكية ولا يصلح قياس RVOL الشامل.
- وثائق Alpaca عن الحساب Basic تشير إلى وصول تاريخي قد يتوفر لبيانات SIP الأقدم من 15 دقيقة. **لا تتعامل مع ذلك كترخيص تلقائي لاستخدام آلي أو إعادة نشر البيانات.**
- يطلب البوت فقط `feed=sip` و`timeframe=1Day` مع `end` عند **بداية اليوم الحالي في نيويورك**، وبالتالي يستخدم الأيام الماضية المكتملة فقط.
- إذا رفض المصدر بـ401/403/429، **لا يوجد التفاف أو استخدام بيانات مزيفة أو إعادة جلب من Yahoo**. يتحول التقرير إلى `INTERNAL_NO_VALID_BARS` ويذكر عدد الأخطاء بدون مفاتيح أو أسعار.

## 2. خطوة مالك الحساب على GitHub

لا ترسل مفاتيح API داخل المحادثة أو تضعها في مستودع عام.

على صفحة المستودع `GHAZMOTIEBIPRO/GHAZIBOT`:

1. `Settings → Secrets and variables → Actions → Secrets` أضف `ALPACA_API_KEY` و`ALPACA_SECRET_KEY` من حساب Alpaca **الذي تسمح رخصته بالاستخدام الداخلي الآلي**.
2. `Settings → Secrets and variables → Actions → Variables` أضف `ALPACA_INTERNAL_DATA_USE_AUTHORIZED=true` **فقط بعد تأكيد هذا الحق**.
3. للوصول التاريخي SIP تحديدًا، وبعد التأكد أنه مسموح للحساب، أضف `ALPACA_HISTORICAL_SIP_INTERNAL_AUTHORIZED=true`. من دون هذا المتغير سيظل `feed=iex` فقط.
4. إذا سمح ترخيصك بتوجيه **مشتقات بحثية خاصة** إلى حساب Telegram الخاص بك، يمكن وضع `ALPACA_PRIVATE_ALERTS_AUTHORIZED=true` منفصلًا. ليس شرطًا لتشغيل البحث، ولا يمنح حق النشر العام.
5. افتح `Actions → GHAZI RADAR Alpaca IEX Private VCP Research → Run workflow`. راجع `bot-state/runtime/public/data/alpaca_iex_vcp_health.json`. لا ينبغي ظهور أسعار أو رموز أسهم في ذلك التقرير.

## 3. التمييز الإجباري بين درجات الثقة

- `INTERNAL_RESEARCH`: تم استلام بعض الشموع التاريخية الصالحة، ولم يتم إثبات قوة الإشارة ولا تنفيذ الأوبشن.
- `INTERNAL_NO_VALID_BARS`: لا توجد سلسلة مؤهلة رغم المحاولة، ولا يجوز الادعاء أن تحليلات الأسهم تعمل.
- `PROVIDER_TERMS_UNATTESTED` أو `CREDENTIALS_MISSING`: لم تحدث **أي** محاولة اتصال بالمصدر.
- `HISTORICAL_SIP_ONLY_NOT_REALTIME`: مصدر سوق متكامل على مستوى شموع **جلسات ماضية**، لكنه ليس تحديثًا لحظيًا ولا تأكيدًا مستقلًا، كما أنه لا يؤهل عقود الأوبشن.
- فحص Alpaca وحده (سواء IEX أو SIP) **ليس مزودين مستقلين**. تأكيد الأسعار يحتاج عائلة مصدر ثانية صاحبة ترخيص، كـMassive Basic لنهاية اليوم ضمن شروط حساب المالك.

## 4. طريق الأوبشن والتجارب

- Alpaca Basic option `indicative` **ليس OPRA NBBO**. يمكن استخدامه في تجربة بحثية مؤخرة، لكنه لا يسمح باعتبار الأسعار قابلة لتنفيذ الصفقات الحية.
- Tradier Brokerage API يوفر للأسهم والأوبشن بيانات حية للمؤهلين من أصحاب الحسابات الأمريكية، لكنه ليس حلًا عامًا أو قابلًا لإعادة النشر؛ لا تربطه بإشارات عامة دون تصريح.
- للاختبار: احتفظ بقرار الإشارة وقت وقوعه، المصدر والتوقيت، الـOCC contract id والسعر bid/ask مؤرخًا، أدنى وأعلى سعر لاحق، السبريد، التكلفة والانزلاق، ثم قيّم في عينة جديدة عبر 10 جلسات مستقلة على الأقل وأفق ثابت وتفريق واضح بين 0DTE و14–30 DTE.
- لا يُسمح بقياس نتائج العقد كأرباح حقيقية إذا لم تُقاس أسعار دخول ask وخروج bid المؤهلة، ولا يجوز ترقية جودة الاستراتيجية بمجرد 100+ حالة قديمة.
