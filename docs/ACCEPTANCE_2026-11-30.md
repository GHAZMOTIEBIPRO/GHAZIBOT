# قائمة قبول جلسة الاثنين 30 نوفمبر 2026

الجلسة كاملة: الافتتاح 09:30 والإغلاق 16:00 نيويورك (17:30 و00:00 الرياض)، والتوقيت الشتوي EST.

**تعريف الحالات:**
- **DELIVERED**: قبول Bot API للرسالة، وليس إشعار قراءة.
- **UNCONFIRMED**: لا يُعاد إرساله تلقائياً. يُراجع يدوياً ثم يُثبّت بـ `/confirm`.
- لا يُعد نجاح CI ولا اختبار تيليجرام المحاكى دليلاً على التسليم.

## قبل الجلسة (المالك)
1. دمج #464 ثم #465 ثم #466 بـ «Create a merge commit». قارن SHA الإنتاج بـ `git log -1 main`.
2. إضافة سر واحد في Settings ← Secrets and variables ← Actions (لم يعد مفتاح الحالة مطلوباً؛ لا تخزين):
   - `SEC_USER_AGENT`: بصيغة `GhaziRadar اسم@بريد`.
3. تشغيل `settings-check.yml` يدوياً: يطبع `preflight engines` لكل محرك و`FULL_READY`، دون أي قيمة سرية.
