# Recommended architecture: 16–20 A4 portrait pages

This is a decision framework rather than a requirement to pad content. Allocate more room to real projects and less to slogans. If evidence is scarce, produce 8–12 pages and a proposed completion roadmap.

1. Cover: real architecture / construction visual; exact legal name; short capability proposition.
2. Executive snapshot: identity, city, verified activities, who we serve (without inventing numbers).
3. Who we are: precise institution overview + short purpose/vision only if approved.
4. Why engage us: 3–5 *defensible* buyer benefits tied to method, not boastful claims.
5. Service architecture: services by actual registered and performed scope.
6. Civil and building works: real capability description.
7. Finishes / fit-out / renovation: include only if practiced and documented.
8. MEP / infrastructure / other scopes: include only when supported; otherwise use validated relevant services.
9. Work methodology: inquiry -> survey -> planning -> procurement -> execution -> handover.
10. Quality, HSE and risk: actual controls; distinguish aspirations from documented certifications.
11. Operational delivery: supervision, scheduling, supplier and subcontractor management (if genuine).
12. Selected project 1: photo(s), type, location, scope, dates, delivery status, role, verified.
13. Selected project 2: same evidence-based structure.
14. Selected project 3 or photographic gallery: ONLY if real documented assets.
15. Project map / portfolio breakdown: ONLY with verifiable data; never invent KPIs.
16. Organizational capabilities / people: role-based organizational structure, no private data.
17. Official credentials: licenses, valid certificates, registrations; exact dates and status checked.
18. Partnerships/clients: logos only with actual business relationship and permission.
19. Why us / contact route: concise concrete proposition, next action.
20. Back cover: exact verified contact information, scannable links, logo.

## Project evidence card schema
- Name (official contract name or a permitted generic label)
- Owner/client (permission + evidence)
- City/area
- Work category, precise scope, role (prime/subcontractor)
- Year or duration (supported)
- Status (completed / in progress / unspecified)
- Deliverables and measurable metrics (source required)
- Authentic photographs with origin and reuse permission
- Source file name/page/reference and internal verification status

## Saudi audience variants
- Developer/owner: delivered work, QA, timely communication, response reliability.
- Private client: services, process, warranty scope when evidenced, before/after imagery.
- Prequalification: corporate details, technical capacity, past works, HSE and documents; do not assert that a marketing PDF itself meets tender qualification criteria.
