# Acceptance checks before delivering

## Evidence safety
- [ ] Every project, client logo, delivered value, quantity and credential can be traced to an attached source.
- [ ] No confidential financials, personal employee information, case numbers or internal disputes appear accidentally.
- [ ] Legal business name and current contact information verified.
- [ ] Expiring permits/certifications show correct status and no expired credential is shown as current.
- [ ] Stock images/AI illustrations are not described as real work executed by the entity.

## Arabic/editorial
- [ ] No backwards letters, broken joins, Latin punctuation drift or LTR layout masquerading as RTL.
- [ ] Technical terms consistent, spelling and diacritics natural.
- [ ] Every page has a clear business purpose; no needless repetition or filler.
- [ ] Numeric tables and project cards have clear labels and units, if included.

## Visual QA
- [ ] Render and inspect ALL pages, not only cover and random samples.
- [ ] Compare PPTX renders against PDF renders; revise layout until reasonably consistent.
- [ ] No clipping, overlapping, low-contrast text, tiny copy, unsafe edge placement, pixelated photos, or orphan lines.
- [ ] Brand fonts, palette and proportions consistent.
- [ ] QR destinations work and no placeholder QR is presented as real.
- [ ] Page sequence and hyperlinks function; file opens on common mobile and desktop viewers.

## Delivery
- [ ] Editable PPTX + final PDF present and named consistently.
- [ ] Report lists any missing sources and public claims omitted for lack of evidence.
- [ ] Provide one-page review summary and human approval step before external circulation.
