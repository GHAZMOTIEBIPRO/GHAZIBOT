# Surah Al-Insan — Quran Cinematic Video

مشروع مستقل داخل فرع `agent/quran-cinematic-video` لإنتاج فيديو سينمائي عمودي قصير مستلهم من معاني سورة الإنسان، مع الالتزام بالضوابط التالية:

- لا تجسيد لله سبحانه وتعالى.
- لا إظهار للأنبياء أو نسبة هيئة تخمينية إليهم.
- لا تصوير للجنة أو النار على أنه وصف حقيقي قطعي؛ المشاهد الغيبية تبقى تفسيرية/تأملية فقط.
- لا إدخال نص قرآني بواسطة مولد الفيديو نفسه لتجنب أخطاء الحروف.
- لا موسيقى في النسخة الناتجة من خط الإنتاج هذا.
- المشاهد البشرية العامة شخصيات مجهولة وليست إعادة بناء لشخصيات تاريخية.

## التنفيذ

تقوم GitHub Actions بتشغيل `generate.py`، الذي يستدعي واجهة Gradio العامة لـ `Lightricks/ltx-video-distilled` في وضع Text-to-Video، ثم يوحّد اللقطات إلى 1080×1920 / 24fps ويجمعها في:

`projects/quran-cinematic/output/surah_al_insan_cinematic_9x16.mp4`

ويُرفع الناتج كـ GitHub Actions Artifact باسم `surah-al-insan-cinematic-video`.

## ملاحظة المصادقة

المحاولة الافتراضية تستخدم الـSpace العام بلا مفتاح. إذا فرض Hugging Face تسجيل الدخول أو الحصة، يمكن إضافة Secret اختياري باسم `HF_TOKEN` إلى المستودع ثم إعادة تشغيل الـworkflow، بدون كتابة المفتاح داخل الكود.
