# رادار الخصومات — BLACK BOX V4.2 Production Standalone

نسخة إنتاج مستقلة من رادار الخصومات مبنية لتغطية أكبر عدد عملي من المصادر مع الحفاظ على صحة السعر والمخزون والشحن.

## الواجهة
ثلاث بوابات رئيسية:
1. 🇸🇦 عروض السعودية — الشركات والمحلات والمتاجر والخدمات داخل السعودية.
2. 🌍 عروض عالمية — متاجر عالمية تشحن إلى السعودية أو لها واجهة سعودية.
3. ✨ منوع — خلاصة متنوعة تمنع متجرًا أو فئة واحدة من احتكار الصفحة.

## البيانات
- Source Universe V4.2: أكثر من 160 مصدرًا بين متاجر مباشرة ومصادر اكتشاف.
- المتاجر المباشرة تفحص بالتناوب الذكي عبر 4 دورات يومية.
- المصادر عالية الأولوية والموسمية تدخل كل دورة.
- اكتشاف Sale / Outlet / Clearance / National Day من صفحات المتجر نفسها.
- fallback إلى homepage + robots.txt + sitemap عند ضعف صفحات البداية.
- اليوم الوطني السعودي 96 له Seasonal Campaign Engine من أواخر يوليو حتى 26 سبتمبر.

## الجودة
- لا نشر بلا رابط منتج 2xx + سعر + مخزون + شحن/واجهة سعودية.
- RRP/MSRP وحده لا يصنف خصمًا حقيقيًا.
- Price history 7/30/90 يوم.
- إزالة التكرار + Deal Score + Source Health.
- لا تجاوز CAPTCHA / 403 / Login.

## التشغيل
```bash
npm test
npm run scan
npm run serve
```
